# 读取文档 大文件与图片

WebAgy 的 [12 项工作区工具](AGENT_TOOLS.zh-CN.md)包括文档与二进制读取、检索、整理、命令和本地 Skills。Word 可以直接读取，文件夹授权、只读权限和暂停开关依然生效。

| 文件 | 默认读取结果 |
| --- | --- |
| TXT、MD、代码、CSV、XVG、日志、SVG 等文本 | 分段文字；文件本身没有 2 MiB 读取上限 |
| DOCX、PPTX、XLSX、ODT、ODP、ODS、ODG、RTF、EPUB | 提取正文/表格/幻灯片文字；列出可读的内嵌图片 |
| PDF | 提取文字；可另外查看指定页面的图形预览 |
| PNG、JPEG、WebP、GIF、TIFF、BMP、AVIF | 缩放后的图像型 MCP 结果；动图默认首帧 |
| NPY、NPZ | 数组形状、数据类型和常见数值的分段样本；不执行 object/pickle |
| ZIP | 条目列表；用 `member` 指定条目，文字/NPY 可直接读取，不落盘解压 |
| 其他二进制，如专用模拟轨迹、模型或可执行文件 | 有界原始字节和文件信息；不代表已经理解其专业语义，不执行文件 |

## 分段续读

每次默认最多返回 200 行、48,000 字符，可通过 `lines` 与 `max_chars` 调整，单次最多 1,000 行、64,000 字符。`has_more=true` 时，将 `next_cursor` 原样作为下一次的 `cursor`，保留相同路径和编码。游标绑定文件版本；文件变化后需重新读取。超长单行也能续读，不会无限制装入上下文。

大文本未读到结尾时，`total_lines` 可能为 null；根据 `has_more` 和 `next_cursor` 继续，不要把 null 当作空文件。`offset` 仍是从 0 开始的行号。默认识别 UTF-8/带 BOM 的 UTF-16；旧编码可指定 `view=text, encoding=gb18030` 或 `windows-1252`。

`list_files` 返回 `{ entries, total_entries, offset, has_more, next_offset }`。目录有后续页时，将 `next_offset` 作为下次的 `offset`。程序客户端应读取 `entries`，不能再把整个结果视为数组。默认每页 500 项，最多 1,000 项；不会隐藏第 501 项之后的文件。

## 查看图和页面

- Word 等文档首先返回正文及 `images` 列表。需要看某张图时，再对同一路径调用 `read_file(view=image, image_index=0)`；图片编号从 0 开始。
- PDF 对同一路径调用 `read_file(view=image, page=1)`；页码从 1 开始。扫描 PDF 没有文字层时，用页面预览查看。
- 图像预览默认最大边 2,048 像素，可用 `width` 调整至 256–4,096。预览限 2 MiB，原始图片不变。原图细节需要更高分辨率或另行上传时，不能把缩略图当作无损原图。
- 图像只作为 MCP `image` 内容返回一次，不把 Base64 同时塞进文字。标准 MCP 客户端已检查；不同版本的 Gemini 官网是否消费图像结果，仍需官网实测。只读到正文不能声称已看过插图。

## 数组 压缩包与原始数据

NPZ 首次返回归档条目；选择 `member="values.npy"` 后，返回该数组的数据类型、形状、存储顺序和数值。数值按存储顺序排列，`offset` 是元素偏移、`lines` 是最多返回的元素数。普通 NPY 文件同样适用。复杂结构化/对象数组目前只提供元数据，不反序列化 pickle。

`view=binary` 可读取任意普通文件的原始字节。默认 4,096 字节，单次最多 65,536；返回 Base64、短十六进制预览及 `next_byte_offset`。这解决字节访问，不代替 GROMACS、MATLAB 等专用格式解析。

## 解析范围

文档/图片/容器单次输入限 256 MiB，ZIP 限 10,000 项、声明展开大小 512 MiB，提取正文限 16 MiB，解析超时 45 秒。超过解析范围的文件仍可分段读取原始字节。普通大文本不受 256 MiB 输入限制。Word 中高分辨率图片不会随每次正文读取一起发送。

不运行宏、代码或附件，不联网下载 OCR 数据，不向所选文件夹写提取中间文件。旧式 `.doc`/`.xls`、加密文档及未知格式不保证提取正文。文本写入与精确编辑仍维持 2 MiB 上限，并拒绝用纯文本覆盖 Office、PDF、图片和常见专业二进制文件；本轮扩展的是读取能力。

更新后建议使用新对话或任务。连接地址无需因工具更新而更换，1.0.0 工具发现应显示 12 项。
