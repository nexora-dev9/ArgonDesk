ArgonDesk Help

Windows local-folder tools for Gemini · Preview release 0.4.6

First-time setup

  1. Start ArgonDesk and configure your ngrok HTTPS domain and account token.
  2. For a legacy custom app, copy the private MCP URL and keep it secret. For a registered app, use the separate Registered-app MCP endpoint in the OAuth card.
  3. Choose the folder Gemini may access, select read-only or edit access, and enable file access.
  4. For the registered app, configure machine-to-machine OAuth with the Client ID and Client Secret generated by ArgonDesk.

Write confirmations

Manually added custom MCP apps in Gemini require manual confirmation for write actions. A registered app in Google's Connected Apps Platform exposes a per-tool User confirmation setting. If Google grants access to Connected Console, you can configure that setting for the file-write tools after registering and verifying the app. Google may still apply separate safeguards to some actions.

Control access

Use the local dashboard to pause file access, select read-only mode, change the folder, stop the HTTPS tunnel or rotate the connection key. Changing the folder or access mode pauses the current workspace and requires a fresh workspace lookup.

Delete local ArgonDesk data

Stop ArgonDesk, then remove its local .local/state folder from the installation directory to delete the local activity history, connection settings and locally stored keys. This does not delete files in your selected workspace and does not remove data that Google or the tunnel provider may retain under their own policies. Keep a backup of the state folder if you want to preserve the current connection settings.

Supported tools

  • Inspect workspace information and list folders.
  • Read large text files in pages, extract supported document text, and preview images or PDF pages.
  • Create, rewrite, append or batch-edit UTF-8 text files.
  • Create folders within the selected workspace.

Eleven tools also support filename/glob search, text/regex search, moves and Recycle Bin deletion. Preferences separately authorizes file management and PowerShell builds/tests. Command cwd is checked, but commands run as the current Windows user and can access other folders; this is not an OS sandbox. Pausing or revoking command permission stops active command trees.

Preferences can restore the tunnel and saved file permissions when ArgonDesk opens, including when its backend is already running. Changing folders still pauses access and invalidates the previous workspace ID.
