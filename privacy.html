WebAgy Privacy Policy

Last updated: 19 November 2026 · Independent project, not affiliated with Google.

WebAgy is a Windows application that exposes a user-selected local folder through a private MCP endpoint. This policy explains what the application processes and where that information goes.

Information processed

  • When a tool is called, the requested file contents, relative paths, tool arguments and results are processed by WebAgy to perform the requested operation.
  • File contents, tool requests and command stdout/stderr travel through the configured HTTPS tunnel provider (currently ngrok) to Google Gemini. Google processes them under the Google account's applicable terms and privacy settings.
  • WebAgy keeps up to 100 local activity events: tool, path/workspace, command/search query, time, result, duration and exit code. It does not save file bodies or stdout/stderr in history. Credentials embedded in a command string would enter this local history.
  • Local application state may contain the selected folder path, a random MCP capability key, connection settings, an encrypted ngrok token, an optional Google domain-verification token, and an OAuth client ID with a DPAPI-encrypted client secret.
  • When machine-to-machine OAuth is enabled, WebAgy issues short-lived bearer tokens on request. It does not store issued bearer tokens or write OAuth client secrets to the activity history.

Storage and sharing

WebAgy does not operate a cloud database for your files and does not send file contents to an WebAgy-operated analytics service. The local application stores its state on your Windows computer. The configured tunnel provider transports network traffic, and Google receives the information needed to answer your Gemini task. Those providers apply their own terms and privacy policies.

The optional Google domain-verification token is published at the standard verification path on your configured domain so Google can verify domain control. It is not a file-access credential.

Retention and control

The local activity history is capped at the latest 100 events. Local configuration and credentials remain until you remove the application state. You can pause file access, switch to read-only mode, change the selected folder, stop the tunnel or rotate the MCP key in the WebAgy dashboard. Google and the tunnel provider manage their own retention under their respective policies.

Security limits

The legacy custom-app MCP URL contains a random capability key. The registered-app endpoint requires a valid machine-to-machine OAuth bearer token. Keep credentials private and pause access when not needed. File tools enforce folder restrictions; separately authorized commands run as the current Windows user and may access other folders, networks and programs. This is not an operating-system sandbox.

Contact

For project questions, use the WebAgy project page. Do not post private URLs, tokens, personal paths or file contents in public issues.
