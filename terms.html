WebAgy provides folder-scoped text-file tools for a Windows computer selected and controlled by the user. By using the application, you agree to these terms.

Permitted use

Use WebAgy only with folders and files you own or are authorized to access. You are responsible for the instructions you give Gemini, the files you select, the changes you approve through your chosen integration, and compliance with applicable laws and third-party terms.

Functionality and limits

WebAgy provides workspace inspection, directory/file/text search, large-text and supported-document reading, image previews, bounded binary reading, text-file creation/editing, and directory creation. Separate grants enable moving/deleting files and running PowerShell commands for builds/tests. Deletion defaults to the Windows Recycle Bin; explicit permanent deletion is supported. Commands validate their starting directory but retain current-user Windows permissions and can access other folders. They do not run in an OS sandbox or elevate privileges. Individual files are subject to the documented size/format limits.
